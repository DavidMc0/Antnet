Or download it with the Autonomi app

Every file on Autonomi has a unique address, and the free desktop app can fetch this file using it. That's a good choice for very large files, or if this page doesn't work for you.

  1. Get the Autonomi app ↗ for Windows, Mac or Linux.
  2. Open Files, choose Download and paste the address.

The app is also used to run nodes, the computers that store files for the network. You don't need to run one to download.

How this works
  1. 1
    Split and encrypted. Files on Autonomi are split into encrypted chunks spread across many nodes.
  2. 2
    Fetched directly. Your browser finds the nodes holding this file and fetches the chunks from them. No server sends you the file.
  3. 3
    Verified and reassembled. Each chunk is checked, the file is put back together, and downloading is free.

The nodes serving the file can see your IP address, like any peer-to-peer download.
